# No Matter – Editor Foto untuk iPhone

## A. Upload ke GitHub (sekali saja, lewat PC atau HP)
1. Buka https://github.com dan login.
2. Klik **+** (kanan atas) → **New repository**. Nama: `nomatter`. Pilih **Public**. Klik **Create repository**.
3. Di halaman repo, klik **uploading an existing file**.
4. Seret SEMUA file dari folder `No Matter` ini (index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png, apple-touch-icon.png). Klik **Commit changes**.
5. Buka **Settings** → **Pages**. Di "Branch" pilih **main** dan folder **/ (root)** → **Save**.
6. Tunggu 1–2 menit. Alamat aplikasimu: `https://NAMA-GITHUB-KAMU.github.io/nomatter/`

## B. Pasang di iPhone
1. Buka alamat di atas pakai **Safari** (harus Safari).
2. Ketuk tombol **Bagikan** (kotak dengan panah ke atas).
3. Pilih **Tambah ke Layar Utama** → **Tambah**.
4. Ikon **No Matter** muncul di layar utama, buka seperti aplikasi biasa. Setelah dibuka sekali, bisa dipakai tanpa internet.

## C. Cara pakai
- **Pilih Foto** → edit pakai tab di bawah: Filter, Atur, Potong, Cantik, Stiker, Teks, Kuas, Bingkai.
- Stiker/teks: geser dengan 1 jari, cubit 2 jari untuk ukuran & putar.
- Tombol belah dua di atas: **tahan** untuk lihat foto asli.
- **Simpan** → **Simpan ke Foto** → pilih "Simpan Gambar".
